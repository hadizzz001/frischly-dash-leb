                              API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

All endpoints are under: /api/scanner
All endpoints require: JWT authentication + staff/rider/market role

POST /api/scanner/scan-product
   └─ Scan product barcode → get product details

POST /api/scanner/scan-order
   └─ Scan order number → get order with pick progress

POST /api/scanner/pick-item
   └─ Mark item as picked → update progress

POST /api/scanner/skip-item
   └─ Mark item as skipped → record reason

GET /api/scanner/pick-progress/:orderId
   └─ Get current fulfillment progress

POST /api/scanner/complete-order
   └─ Finish order fulfillment → update status

GET /api/scanner/orders
   └─ Get orders ready for picking/fulfillment

═══════════════════════════════════════════════════════════════════════════════
                           QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

1. Install scanner dependencies:
   $ cd scanner
   $ npm install

2. Start Node.js server in one terminal:
   $ npm run dev

3. Start scanner app in another terminal:
   $ cd scanner
   $ npm start

4. Test in browser/device:
   - Open http://localhost:8081 on your device
   - Enter API URL: http://YOUR_IP:5000/api
   - Login with staff credentials
   - Start scanning orders!
